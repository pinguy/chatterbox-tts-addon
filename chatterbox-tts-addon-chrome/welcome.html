Install the backend

Clone or extract the complete source tree, open a terminal in its add-on folder, then run:

bash install.sh

The installer downloads Chatterbox-Nano and uses all detected logical CPU cores except one. GitHub source checkouts can start with the model-default voice; create or select a reference in Voice Lab.
